# Pelagia — Marine Intelligence (Neural Ninjas)

## Run
This is a single-file HTML/CSS/JavaScript website. No Node.js, package installation, framework, or external chart library is required.

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Navigate with the sidebar. Charts are drawn with inline SVG and work offline.

## Included
- Overview dashboard with sample indicators
- Ocean conditions page
- Fisheries page
- Marine biodiversity page
- Filterable sample insight cards
- Responsive sidebar/navigation
- Printable dashboard via Export view

## Data and AI status
This is a frontend prototype with fictional values hardcoded in `index.html`.
- No live marine APIs or data sources are connected.
- No backend or AI model is implemented.
- Insight cards are manually written examples, not AI-generated results.
- The map is illustrative and not geographically accurate.
- Do not use sample values for scientific or operational decisions.
